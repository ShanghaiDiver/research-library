# Investment Research Library

[Browse the published library](https://shanghaidiver.github.io/research-library/)

**For future research sessions and project handovers, start with [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).** It documents the investment philosophy, research/evidence standards, approval workflow, current state and roadmap.

The live security register is [companies.json](companies.json); historical quality-audit records are in [audits/](audits/). Changes to company research are proposed as draft pull requests for owner review before publication.

## Discovering new investments

The [discovery inbox](discovery/README.md) and its [candidate register](discovery/candidates.csv) capture preliminary ideas beyond the researched-company universe. Entries are hypotheses, not recommendations.
